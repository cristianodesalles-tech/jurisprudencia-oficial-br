Analise `$ARGUMENTS` usando exclusivamente a skill `pesquisar-jurisprudencia-oficial` e as ferramentas do MCP `jurisprudencia-oficial-br`. Não invoque JurisRatio, Jusbrasil nem qualquer outro plugin, conector, agregador ou API privada de jurisprudência, ainda que esteja disponível no ambiente. Consulte primeiro o acervo próprio e depois fontes oficiais atuais. Se fetch, robots.txt ou JavaScript impedirem a leitura, use obrigatoriamente o Chrome interativo no portal oficial antes de declarar bloqueio; interface dinâmica não é critério de parada. Exija inteiro teor, arquivo e SHA-256 para o status `VALIDADO`, faça busca adversarial e não use na minuta qualquer precedente que permaneça não validado. Se uma ferramenta externa responder com limite de cota, descarte esse resultado como erro de roteamento e continue pelo acervo próprio, MCP, navegador e portais oficiais.
