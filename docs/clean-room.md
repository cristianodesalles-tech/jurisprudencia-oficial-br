# Protocolo clean-room

O projeto implementa funcionalidade própria a partir de fontes públicas, documentação técnica aberta e requisitos do escritório.

- Não acessar código, modelos, prompts, base organizada ou segredos de concorrentes.
- Não raspar nem coletar resultados de serviços privados para formar o acervo.
- Não usar contas, chaves ou cotas de terceiros para treinamento ou reprodução funcional.
- Obter decisões diretamente de tribunais e dados abertos oficiais.
- Registrar autoria, fonte técnica e decisões de arquitetura.
- Manter nomes, interface, esquema e ranking próprios.
- Usar eventual conector comercial somente dentro de sua licença, como descoberta suplementar, nunca como alimentação do acervo.
