# Segurança

Não reporte dados de processos sigilosos em issues públicas. Para vulnerabilidades, use o canal privado de segurança do repositório GitHub após a publicação.

Credenciais devem permanecer em variáveis de ambiente. Logs de auditoria não devem conter cookies, tokens, CPF, endereço ou conteúdo protegido desnecessário. O plugin não executa arquivos baixados e usa hash apenas para integridade.
